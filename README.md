# کیوسک شوروم

قفل متن‌باز و بدون لایسنس برای تبلت اندروید، ساخته‌شده برای Galaxy Tab A11+ در سالن نمایش خودرو. مشتری فقط کروم و حداکثر دو برنامهٔ دیگر را می‌بیند. خودِ اندروید جلوی خروج را می‌گیرد، نه یک لایهٔ شناور روی صفحه.

برنامهٔ رایگانی که با سرویس دسترس‌پذیری یا پنجرهٔ روی صفحه کار می‌کند با One UI سامسونگ می‌جنگد و بعد از آپدیت می‌شکند. این پروژه Device Owner است و از Lock Task رسمی اندروید استفاده می‌کند. لایسنس Knox لازم نیست.

## چه چیزی قفل می‌شود

- صفحهٔ اصلی فقط برنامه‌هایی را نشان می‌دهد که مسئول انتخاب کرده است. سقف، سه برنامه است و کروم برنامهٔ پیش‌فرض است.
- دکمهٔ Home به همین صفحه برمی‌گردد تا مشتری بین همان برنامه‌ها جابه‌جا شود. برنامه‌های دیگر، تنظیمات، فروشگاه Play و نوار اعلان در حالت قفل باز نمی‌شوند.
- بعد از روشن شدن تبلت، اگر بخواهید، کروم روی آدرس شوروم باز می‌شود.
- اگر فهرست سایت بدهید، خودِ کروم سایت‌های دیگر را می‌بندد. خالی بودن فهرست یعنی کروم آزاد است.
- ورود به حساب گوگل داخل کروم، حالت ناشناس و ذخیرهٔ رمز عبور به‌طور پیش‌فرض خاموش است.
- تا وقتی تبلت به برق وصل است صفحه خاموش نمی‌شود. اگر از برق جدا شود، بعد از پنج دقیقه خاموش می‌شود.
- رمز مسئول جدا از قفل اندروید است. پنج بار اشتباه، یک دقیقه قفل می‌شود و بعد طولانی‌تر.
- تنظیمات کیوسک در حافظهٔ محافظت‌شدهٔ دستگاه ذخیره می‌شود تا بعد از ری‌استارت، قبل از باز شدن صفحه، قفل دوباره اعمال شود.
- در حالت قفل، USB debugging بسته است. برای `adb` دوباره، تعمیر را باز کنید و «اجازهٔ USB debugging در حالت قفل» را روشن کنید.

برای ورود مسئول، عنوان را دو ثانیه نگه دار، یا هفت ضربهٔ پشت‌سرهم روی عنوان یا زیرعنوان بزن. بین ضربه‌ها بیشتر از یک و نیم ثانیه فاصله نینداز. این را به مشتری نگویید.

## محدودیت‌ها

- ریکاوری سخت‌افزاری هنوز می‌تواند تبلت را پاک کند. برای همین روی تبلت حساب گوگل نسازید، وگرنه بعد از ریست، قفل FRP حساب گوگل را می‌خواهد.
- نوار آدرس کروم می‌ماند. بستن سایت‌ها با فهرست مجاز کروم انجام می‌شود، نه با مخفی کردن نوار.
- اگر فایل کلید امضا گم شود، نسخهٔ جدید روی تبلت‌های ثبت‌شده نصب نمی‌شود و هر ۱۱۰ تا باید ریست کارخانه شوند.
- اولین تبلت پایلوت است. روی همان واحد، دکمهٔ Home، لبهٔ صفحه، هر دو دکمهٔ صدا (TalkBack)، منوی صفحه‌کلید و Circle to Search را امتحان کنید. اگر یکی از این‌ها از قفل خارج شد، همان را قبل از تکثیر ۱۱۰ تا بنویسید و ببندید.

## ساخت

JDK 17 یا جدیدتر و Android SDK 35 لازم است. Android Studio هر دو را می‌آورد. در ریشهٔ پروژه:

```bash
./gradlew :core:test :app:assembleRelease
```

اولین اجرا این دو فایل را می‌سازد و در گیت نمی‌آیند:

- `keystore/showroom-kiosk.jks`
- `keystore.properties`

هر دو را همان روز روی یک دیسک جدا و در مدیر رمز کپی کنید. رمزها داخل `keystore.properties` هستند. این کلید برای همیشه هویت برنامه روی تبلت است. `applicationId` هم بعد از ثبت اولین تبلت قابل عوض کردن نیست؛ اگر نام بستهٔ دیگری می‌خواهید، قبل از پایلوت در `app/build.gradle.kts` عوضش کنید و همان نام را در `scripts/provision-adb.sh` و `scripts/make-provisioning-qr.py` هم عوض کنید.

APK اینجاست:

```text
app/build/outputs/apk/release/app-release.apk
```

نسخهٔ debug را نصب نکنید. اندروید آن را به‌عنوان مالک دستگاه رد می‌کند.

## پایلوت روی یک Tab A11+

تبلت اندروید ۱۶ و One UI 8 است. مدل وای‌فای SM-X230 و مدل 5G معمولاً SM-X236 است.

1. آپدیت سیستم را قبل از قفل تمام کنید. بعد از قفل، اعلان آپدیت دیده نمی‌شود.
2. ریست کارخانه. در راه‌اندازی اولیه هیچ حساب گوگل و هیچ حساب سامسونگی نسازید.
3. کروم را باز کنید تا مطمئن شوید نصب است. دو برنامهٔ دیگر را هم قبل از قفل نصب کنید. بدون حساب گوگل، نصب از Play ممکن نیست؛ APK را با `adb install` بدهید.
4. ناوبری را روی سه دکمه بگذارید، Edge Panel و DeX و Game Launcher را خاموش کنید.
5. کابل USB-C و `adb` را وصل کنید و اجرا کنید:

```bash
scripts/provision-adb.sh
```

6. روی تبلت «تنظیم مسئول» را بزنید، رمز ۶ تا ۱۲ رقمی بگذارید، کروم و حداکثر دو برنامه را انتخاب کنید، آدرس شروع را بنویسید و «روشن کردن کیوسک» را بزنید.
7. برق را وصل کنید. تبلت باید کروم را باز کند. Home باید فقط به صفحهٔ کیوسک برگردد. تنظیمات، اعلان و فروشگاه نباید باز شوند.
8. عنوان را دو ثانیه نگه دار، یا هفت ضربهٔ سریع روی آن بزن. رمز را وارد کن و «باز کردن تعمیر» را بزن. تنظیمات اندروید فقط در تعمیر باز می‌شود. تعمیر ۱۰ دقیقه باز می‌ماند و با یک دکمه تا ۳۰ دقیقه تمدید می‌شود. ری‌استارت، تعمیر را می‌بندد و دوباره قفل می‌کند.
9. اگر رمز را گم کردید، از صفحهٔ مسئول و بعد از وارد کردن رمز، «پاک کردن این تبلت» را بزنید و `RESET` را تایپ کنید. مسیر دیگر: تبلت خاموش، Volume Up و Power را با هم نگه دارید تا نشان سامسونگ بیاید، Power را رها کنید و Volume Up را نگه دارید. ترکیب دکمه‌ها را روی همین واحد تأیید کنید و روی کارت مسئول بنویسید.

تا وقتی این نه قدم روی یک تبلت تمیز نباشد، سراغ ۱۰۹ تای دیگر نروید.

## ثبت ۱۱۰ تبلت با QR

برای هر تبلت یک بار `adb` کند است. بعد از پایلوت، همان APK را روی یک آدرس HTTPS بگذارید که تبلت در وای‌فای سالن بتواند دانلودش کند. فایل باید بایت‌به‌بایت همان APK ساخته‌شده باشد.

```bash
python3 scripts/make-provisioning-qr.py \
  --url https://example.com/showroom-kiosk.apk \
  --pin 123456 \
  --packages com.android.chrome,com.example.catalog \
  --start-url https://example.com/cars \
  --allowlist example.com \
  --title "شوروم خودرو" \
  --wifi-ssid Showroom \
  --wifi-password "the-wifi-password"
```

خروجی در `provisioning/out/` است و گیت نمی‌شود، چون رمز وای‌فای و PIN داخلش است. اگر `qrcode` نصب نباشد فقط JSON نوشته می‌شود:

```bash
pip install qrcode[pil]
```

وای‌فای راه‌اندازی باید WPA2-Personal باشد. WPA3-only و وای‌فای سازمانی را اول روی یک تبلت امتحان کنید.

روی تبلت نو، در اولین صفحهٔ راه‌اندازی شش بار روی صفحه بزنید تا دوربین QR باز شود. One UI 8 ممکن است جای این حرکت را عوض کرده باشد؛ اگر روی پایلوت باز نشد، همان واحد را با `adb` ثبت کنید و حرکت درست را برای بقیه یادداشت کنید.

`PROVISIONING_LEAVE_ALL_SYSTEM_APPS_ENABLED` در QR روشن است. بدون آن سامسونگ کروم و برنامه‌های سیستمی را موقع ثبت‌نام خاموش می‌کند.

QR را در سالن نگذارید. اگر لو رفت، رمز مسئول را روی هر تبلت عوض کنید. خودِ برنامه از راه دور رمز را عوض نمی‌کند.

## فایل ناوگان برای عوض کردن آدرس بدون دست زدن به ۱۱۰ تبلت

در تنظیم مسئول یک آدرس HTTPS برای فایل JSON بگذارید. نمونه در `deploy/fleet-config.example.json` است. فیلدی که در فایل نباشد عوض نمی‌شود. توکن را در هدر `Authorization: Bearer` می‌فرستد و فقط به همان میزبان.

این آدرس کلید اصلی ناوگان است. کسی که فایل را عوض کند می‌تواند کیوسک را باز کند یا برنامهٔ مجاز را عوض کند. آن را مثل رمز نگه دارید.

برای یک‌بار ری‌استارت همهٔ تبلت‌ها `configRevision` را از مقدار قبلی بزرگ‌تر کنید و `"reboot": true` بگذارید. همان شماره دوباره ری‌استارت نمی‌کند. بعد `reboot` را false کنید.

قفل از راه دور فقط وقتی اعمال می‌شود که روی تبلت از قبل رمز مسئول گذاشته شده باشد.

به‌روزرسانی خودِ کیوسک:

```json
{
  "configRevision": 2,
  "versionCode": 2,
  "apkUrl": "https://example.com/showroom-kiosk.apk",
  "apkSha256": "64 lowercase hex characters"
}
```

`versionCode` در `app/build.gradle.kts` باید همان عدد باشد و APK با همان کلید امضا شده باشد. برنامهٔ دوم و سوم را هم می‌شود با `extraApks` داد. هر کدام `packageName` و `url` و `sha256` و `versionCode` می‌خواهند. نصب بی‌صدا را روی پایلوت اندروید ۱۶ حتماً یک بار ببینید. اگر سیستم جلویش را گرفت، در حالت تعمیر با `adb install -r` به‌روز کنید.

دکمهٔ «کپی فایل ناوگان» JSON فعلی را بدون رمز و بدون توکن می‌دهد. اگر `"kioskEnabled": false` داخلش باشد، منتشرش نکنید؛ تبلت‌ها باز می‌شوند.

## حالت تعمیر و پشتیبانی

| کار | مسیر |
| --- | --- |
| تنظیمات، وای‌فای، آپدیت سیستم | نگه داشتن عنوان یا هفت ضربه، رمز، باز کردن تعمیر |
| برگشت به قفل | «قفل کردن دوباره» یا تمام شدن مهلت یا ری‌استارت |
| پاک کردن یک تبلت | رمز، سپس RESET، یا ریکاوری سخت‌افزاری |
| دیدن سیاست کروم | موقتاً فهرست سایت را خالی کنید، کروم را باز کنید و `chrome://policy` را ببینید |

فهرست سایت مثل سیاست سازمانی کروم است: `example.com` یا `https://example.com/cars`. ستاره به‌تنهایی قبول نمی‌شود. خالی یعنی همه‌چیز مجاز است.

## اگر `set-device-owner` شکست خورد

- «accounts» یعنی یک حساب روی تبلت مانده. ریست کارخانه و رد کردن هر حسابی.
- «testOnly» یا «not allowed» یعنی APK دیباگ نصب شده. APK ریلیز را نصب کنید.
- «checksum» در QR یعنی فایل روی سرور با APKی که اسکریپت دیده یکی نیست. همان فایل را دوباره آپلود کنید و QR را از نو بسازید.
- «already provisioned» یعنی این تبلت قبلاً مالک دارد. برای عوض کردن مالک باید پاک شود.
